# Fate/Grand Order — Segundo Cérebro

## Tema e objetivo

Criar um segundo cérebro sobre o sistema de fortalecimento de Servants em Fate/Grand Order, reunindo informações confiáveis sobre níveis, Ascension, Skills, Noble Phantasm e materiais necessários para evoluir os Servants.

## Fontes utilizadas

### Fate/Grand Order Official USA

A documentação oficial do Fate/Grand Order foi utilizada como principal fonte por ser publicada oficialmente para explicar os sistemas do jogo.

Ela contém informações sobre o menu Enhance, uso de Embers para aumentar níveis, Hero Crystals, fortalecimento de Skills, fortalecimento de Craft Essences e Palingenesis.

**Fonte:** Fate/Grand Order Official USA — How to Play

### GamePress — Leveling and Upgrades

A GamePress foi utilizada como fonte complementar para informações detalhadas sobre progressão de Servants.

A página apresenta os limites de nível por raridade, progressão através de Ascension, materiais necessários, Noble Phantasm e Skill Enhancement.

**Fonte:** GamePress — Leveling and Upgrades

### GamePress — Materials

A seção de materiais da GamePress foi utilizada para consultar a função dos diferentes materiais e suas relações com Ascension e Skill Enhancement.

**Fonte:** GamePress — Materials

## Diretriz de comportamento do notebook

O notebook foi instruído a responder exclusivamente utilizando as fontes fornecidas.

Cada informação factual deve indicar a fonte que a sustenta. Quando mais de uma fonte for utilizada, todas devem ser identificadas.

Caso as fontes não contenham informação suficiente para responder a uma pergunta, o notebook deve informar que não encontrou informação suficiente nas fontes, em vez de utilizar conhecimento externo ou inventar uma resposta.

A documentação oficial deve ser priorizada quando fornecer diretamente a informação solicitada, enquanto as fontes secundárias devem ser utilizadas para complementar informações que não estejam detalhadas na documentação oficial.
